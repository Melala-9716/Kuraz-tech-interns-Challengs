# Week 3, Day 2: PHP OOP Practice

## Objective
Practice the fundamentals of object-oriented programming in PHP.

## Planned Classes
1. **Student:** Store and display student information.
2. **Product:** Calculate the total cost of a product based on price and quantity.
3. **BankAccount:** Practice deposits and encapsulation.

## Concepts
- Classes and objects
- Properties and methods
- Constructors
- The `$this` keyword
- Access modifiers (`public` and `private`)
- Return values

## Technology
PHP, tested locally using XAMPP.
