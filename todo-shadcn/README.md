# Todo App

A simple Todo List application built with React and Shadcn UI.

## Features

* Add tasks
* Delete tasks
* Move tasks up and down
* Press Enter to add a task
* Styled using Shadcn UI components

## Technologies

* React
* JavaScript
* Tailwind CSS
* Shadcn UI
* Vite

## Run the Project

```bash
npm install
npm run dev
```
