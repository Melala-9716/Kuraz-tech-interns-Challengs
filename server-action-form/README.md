# Server Action Form

A simple contact form built with Next.js Server Actions. The form uses `FormData` to handle user input, processes the submission on the server, and includes a loading state with `useFormStatus` while the request is being processed.

## Features

* Server Action form submission
* FormData handling
* Mock server-side write
* Loading state with `useFormStatus`
* Responsive styling with Tailwind CSS

## Tech Stack

* Next.js
* React
* Tailwind CSS
* JavaScript
