Pokémon Loading & Error

A Next.js project that fetches Pokémon data from the PokéAPI and demonstrates loading and error handling.

Features
Fetches Pokémon data from the PokéAPI
Displays Pokémon images and information
Uses Promise.all() for multiple API requests
Includes a loading.jsx loading state
Includes an error.jsx error state
Uses a Server Action for the feedback form
Uses useFormStatus() for the form submission state
Styled with Tailwind CSS
What I Learned

This project helped me understand how Next.js handles data fetching, loading states, error handling, Server Actions, and asynchronous operations.

Tech Stack
Next.js
React
Tailwind CSS
PokéAPI
