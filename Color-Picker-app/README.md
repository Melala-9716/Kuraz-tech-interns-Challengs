# Color Picker App

A simple React application built with Vite that allows users to select a color and see the selected color displayed dynamically.

## Features

* Select colors using a color picker
* Display the selected color value
* Update the UI based on the chosen color
* Simple and interactive user interface

## Technologies Used

* React
* JavaScript
* CSS
* Vite

## What I Learned

* Using `useState` to store and update values
* Handling input changes in React
* Passing values between components
* Updating styles dynamically
* Managing user interactions with React

## How to Run the Project

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
