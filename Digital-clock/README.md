# Digital Clock App

A digital clock application built with React and Vite that displays the current time and updates automatically in real time. The app also includes a dark and bright mode toggle with a custom background design.

## Features

* Displays current hours, minutes, and seconds
* Updates the time automatically every second
* Dark mode and bright mode toggle
* Dynamic background changes based on the selected theme
* Clean and responsive user interface

## Technologies Used

* React
* JavaScript
* CSS
* Vite

## What I Learned

* Using `useState` to manage application state
* Using `useEffect` for timers and side effects
* Working with `setInterval` and cleanup functions
* Formatting time values using JavaScript
* Creating theme toggles with conditional rendering
* Updating UI dynamically with React state

## How to Run the Project

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
