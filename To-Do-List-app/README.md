# To-Do List App

A simple To-Do List application built with React. This project allows users to add, manage, and remove tasks while practicing the fundamentals of React development.

## Features

- Add new tasks
- Delete tasks
- Display tasks dynamically
- Manage user input
- Simple and clean user interface

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Concepts Practiced

- React components
- JSX
- useState hook
- State management
- Event handling
- Conditional rendering
- Working with arrays in React
- Rendering dynamic data
- Project structure and component organization
